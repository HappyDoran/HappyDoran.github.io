struct 또는 enum에서의 인스턴스가 let으로 생성이 된 경우에는 해당 프로퍼티를 변경할 수 없습니다\.

Swift는 특별히 요청하지 않는 한 프로퍼티를 변경하는 메소드를 허용하지 않습니다\. 즉 값 타입의 속성은 기본적으로 인스턴스 메서드 내에서 수정할 수 없습니다\.

만약에 내부 속성, 즉 값 타입의 프로퍼티를 수정하려면 인스턴스 메소드에서 mutating 키워드를 사용해야 합니다\.

```swift
struct Person {
    var name: String
 
    mutating func makeAnonymous() {
        name = "Anonymous"
    }
}

var person = Person(name: "Ed")
person.makeAnonymous() //name = "Anonymous"
```

#### 예시

```swift
struct BodyStruct {
    var weight: Double = 0.0
    
    mutating func changedWeight(to weight: Double) {
        self.weight += weight
    }
}

var myWeight = BodyStruct(weight: 60.5)
myWeight.changedWeight(to: 10.2)
print(myWeight) //70.7
```

```swift
enum YesOrNoEnum {
    case yes, no
    mutating func answer() {
        self = self == .yes ? .no : .yes
    }
}

var myAnswer: YesOrNoEnum = YesOrNoEnum.yes
myAnswer.answer() //no
```

### 상수

추후에 변경이 불가능한 상수

let 

#### 상수 선언

```swift
let 이름 : 타입 = 값
```

### 변수

추후에 변경이 가능한 변수

var

#### 변수 선언

```swift
var 이름 : 타입 = 값
```

→ 상수와 변수의 값의 타입이 명확하다면 타입은 생략 가능

```swift
var name = "hello"
```

나중에 할당하려고 하는 상수나 변수는 타입값 필수 

```swift
let sum : Int
let inputA : Int = 100
let inputB : Int = 200

sum = inputA + inputB
```

→ 상수는 할당한 후에 값 변경이 불가하지만 변수는 할당한 후에 값 변경이 가능

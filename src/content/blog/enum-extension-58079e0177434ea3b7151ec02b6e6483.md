## Enum\(열거형\)

가능한 값 목록을 정의하는 사용자 정의 유형을 모델링합니다\.

→ <strong>여러가지 예시나 사실을 낱낱이 쭉 늘어놓는 것</strong>을 의미합니다\.

→ <strong>같은 주제로 연관된 데이터를 멤버로 구성</strong>하여 나타내는 자료형

\(뭐이리 정의가 많음;;;\)

### 기본

```swift
enum CompassPoint {
    case north
    case south
    case east
    case west
}

//이런식으로 한번에 작성할 수도 있습니다.
enum CompassPoint {
		case north, south, east, west
}
```

중괄호 안에 모든 정의를 위치시켜 나타냅니다\.

```swift
var directionToHead: CompassPoint = CompassPoint.east
var directionToHead = .east
```

각 enum의 정의는 새로운 타입으로 정의합니다\.

### Switch 구문을 사용하여 열거형 값 일치

```swift
switch directionToHead {
case .east:
    print("동쪽")
case .north:
    print("북쪽")
case .south:
    print("남쪽")
case .west:
    print("서쪽")
}
```

모든 케이스가 고려되지 않았을 경우에는 default를 사용하여 리스트를 고려해야 합니다\. 

### 연관된 값\(Associated Values\)

```swift
enum Barcode {
    case upc(Int, Int, Int, Int)
    case qrCode(String)
}

var productBarcode = Barcode.upc(8, 85909, 51226, 3)
```

경우에 따라 케이스값과 함께 다른 타입의 값을 저장할 수 있는 것이 유용합니다\. 이 추가적인 정보를 연관된 값\(associated value\)이라 하며, 해당 케이스를 코드에서 값으로 사용할 때 마다 달라집니다\. 

```swift
switch productBarcode {
case .upc(let numberSystem, let manufacturer, let product, let check):
    print("UPC: \(numberSystem), \(manufacturer), \(product), \(check).")
case .qrCode(let productCode):
    print("QR code: \(productCode).")
}
// Prints "QR code: ABCDEFGHIJKLMNOP."
```

마찬가지로 스위치 구문으로 다른 바코드 타입을 확인할 수 있습니다\.

### 원시값\(Raw Values\)

```swift
enum ASCIIControlCharacter: Character {
    case tab = "\t"
    case lineFeed = "\n"
    case carriageReturn = "\r"
}
```

모두 동일한 타입의 기본값으로 미리 채워넣을 수 있습니다\. 

#### 암시적 원시값

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars, jupiter, saturn, uranus, neptune
}

enum CompassPoint: String {
    case north, south, east, west
}

//물론 이렇게 원시값을 초기화 해주는 것도 됩니다.
let possiblePlanet = Planet(rawValue: 7)
```

이렇게 타입을 정해주면  암시적으로 원시값을 가질 수 있습니다\. 예를 들어

venus는 2, earth는 3…

north는 “north”, south는 “south”…

### 재귀 열거형

열거형 케이스에 하나 이상의 연관된 값으로 열거형의 다른 인스턴스를 가지고 있는 열거형입니다\.

indirect를 작성하여 컴파일러에게 필요한 간접 계층을 삽입하도록 지시합니다\.

```swift
enum ArithmeticExpression {
    case number(Int)
    indirect case addition(ArithmeticExpression, ArithmeticExpression)
    indirect case multiplication(ArithmeticExpression, ArithmeticExpression)
}
//or

indirect enum ArithmeticExpression {
    case number(Int)
    case addition(ArithmeticExpression, ArithmeticExpression)
    case multiplication(ArithmeticExpression, ArithmeticExpression)
}

let five = ArithmeticExpression.number(5)
let four = ArithmeticExpression.number(4)
let sum = ArithmeticExpression.addition(five, four)
let product = ArithmeticExpression.multiplication(sum, ArithmeticExpression.number(2))

func evaluate(_ expression: ArithmeticExpression) -> Int {
    switch expression {
    case let .number(value):
        return value
    case let .addition(left, right):
        return evaluate(left) + evaluate(right)
    case let .multiplication(left, right):
        return evaluate(left) * evaluate(right)
    }
}

print(evaluate(product)) // 18
```

## Extension\(확장\)

기존의 클래스, 구조체, 열거형 타입에 새로운 프로퍼티, 메소드, 이니셜라이저를 추가해서 원본 타입에 접근하지 못하는 타입들도 확장해서 쓸 수 있습니다\.

- computed property, computed type property 추가
   → stored property는 불가능 한 것을 뜻하나? 실제로 안되긴 한다\.
- method와 type method 정의
- 새로운 initializer 추가
- 서브 스크립트 정의
- 중첩된 타입 정의

### Extension Syntax\(확장 구문\)

```swift
extension SomeType {
	...
}
```

확장은 하나 이상의 프로토콜을 채택하여 기존 타입을 확장할 수 있습니다\. 프로토콜 준수를 추가할 때 클래스 또는 구조체를 작성하는 것과 동일한 방법으로 프로토콜 이름을 작성합니다

```swift
extension SomeType: SomeProtocol, AnotherProtocol {
    // implementation of protocol requirements goes here
}
```

### Computed Property\(계산 프로퍼티\) 추가

extension은 기존 타입에 computed property와 computed type property를 추가할 수 있습니다\. 

```swift
struct Info {
    var name: String
    var age: Int
}

extension Info {
    var introduce: String{
        get{
            return "제 이름은 \(self.name)입니다."
        }
        set{
            name = newValue
        }
    }
}

var dongwon: Info = Info(name: "서동원", age: 27)

print(dongwon.introduce) // 제 이름은 서동원입니다.

dongwon.introduce = "Seodongwon" 
print(dongwon.introduce) // 제 이름은 hello입니다.
```

### Methods\(메소드\) 추가

기존 타입에 새로운 인스턴스 메소드와 타입 메소드를 추가할 수 있습니다\.

```swift
extension Int {
    func repetitions(task: () -> Void) {
        for _ in 0..<self {
            task()
        }
    }
}

3.repetitions {
    print("Hello!")
}
// Hello!
// Hello!
// Hello!
```

인스턴스 메소드도 수정이 가능합니다\. mutating으로 인스턴스 메소드를 표시해야합니다\. 

```swift
extension Int {
    mutating func square() {
        self = self * self
    }
}
var someInt = 3
someInt.square()
// someInt is now 9
```

### 서브 스크립트, 중첩된 타입 추가\(나중에 다시 보겠습니다\.\)

```swift
extension Int {
    subscript(digitIndex: Int) -> Int {
        var decimalBase = 1
        for _ in 0..<digitIndex {
            decimalBase *= 10
        }
        return (self / decimalBase) % 10
    }
}
746381295[0]
// returns 5
746381295[1]
// returns 9
746381295[2]
// returns 2
746381295[8]
// returns 7
```

```swift
extension Int {
    enum Kind {
        case negative, zero, positive
    }
    var kind: Kind {
        switch self {
        case 0:
            return .zero
        case let x where x > 0:
            return .positive
        default:
            return .negative
        }
    }
}

func printIntegerKinds(_ numbers: [Int]) {
    for number in numbers {
        switch number.kind {
        case .negative:
            print("- ", terminator: "")
        case .zero:
            print("0 ", terminator: "")
        case .positive:
            print("+ ", terminator: "")
        }
    }
    print("")
}
printIntegerKinds([3, 19, -27, 0, -6, 0, 7])
// Prints "+ + - 0 - 0 + "
```

## 그래서 enum과 extension을 어떻게 합쳐서 쓰지?

NC2를 할 때 사용한 제 코드를 들고오겠습니다\.

```swift
enum PathType: Hashable {
    case onboarding
    case selectYear
    case quizFinish
    
    case quiz(questionCount: Int, playTime: Int)
    case quizReady(selectYear: Int, questionCount: Int, playTime: Int)
    
}

extension PathType {
    @ViewBuilder
    func NavigatingView() -> some View {
        switch self {
        case .onboarding:
            OnboardingView()
        case .selectYear:
            SelectYearView()
        case .quizFinish:
            QuizFinishView()
            
        case .quiz(let questionCount, let playTime):
            QuizView(questionCount: questionCount, playTime: playTime)
        case .quizReady(let selectYear, let questionCount, let playTime):
            QuizReadyView(selectYear: selectYear, questionCount: questionCount, playTime: playTime)
        }
    }
}
```

해당 코드는 NavigationStack을 사용하기 위해서 해당 페이지에 따른 케이스 분류를 PathType에 넣어두고 케이스마다 View를 반환해주는 함수 NavigatingView를 extension으로 넣어놓은 코드입니다\. 

위의 코드처럼 여러개의 case에 따라 각각의 View를 표시해줄 때 extension과 합쳐서 사용할 수 있습니다\.

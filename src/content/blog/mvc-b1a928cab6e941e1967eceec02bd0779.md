## MVC 패턴이란?

MVC패턴은 Model \+ View \+ Controller 구조의 아키텍처입니다\.

### Model

앱의 데이터와 비즈니스 로직을 담당합니다\.

주로 struct, class로 만듭니다\.

### View

사용자에게 데이터를 보여주거나 UI를 담당합니다\.

SwiftUI, UIKit을 상속합니다\.

### Controller

Model과 View의 중간다리 역할로 View로부터 사용자의 action을 받아 Model에게 어떤 작업을 해야 하는지 알려주거나, Model의 데이터 변화를 View에게 전달하여 View가 어떻게 업데이트를 할지 알려줍니다\.

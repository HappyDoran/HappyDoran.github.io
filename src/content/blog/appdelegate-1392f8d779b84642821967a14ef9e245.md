## Life Cycle이란?

생명주기라는 것은 앱의 최초 실행부터 앱이 완전히 종료되기까지 앱이 가지는 상태와 그 상태들 사이의 전이를 뜻합니다\. 앱의 상태는 앱이 현재 어떠한 것을 할 수 있는가를 결정합니다\.

## App’s Life Cycle이란?

App의 생명 주기는 App의 실행/ 종료 및 App이 Foreground\(실행중\)/Background\(앱에서 바깥으로 나가진 상태, 종료는 아님\) 상태에 있을 때, 시스템이 발생시키는 event에 의해 App의 상태가 전환되는 일련의 과정을 뜻합니다\.

## 앱의 상태\(App State\)

![](<../../assets/blog/appdelegate-1392f8d779b84642821967a14ef9e245/image-001.png>)

앱은 실행되는 동안 다양한 상태로 변화합니다\. 여기서 말하는 상태는 화면에 나타났거나, 화면에 숨겨지거나, 시작했거나 종료됐거나 하는 등을 의미합니다\.

앱의 상태 변화는 운영체제가 처리하는 영역입니다\. 아이폰의 경우 iOS 운영체제가 시스템의 상황에 맞게 발생하는 상황에 맞춰 앱의 상태를 변화시키고 제어합니다\. 

이러한 상태변화를 iOS는 총 5가지로 나눕니다\.

<strong>Unattached\(Not\-Running\)</strong>

- 앱이 시작되지 않았거나 실행되었지만 시스템에 의해 종료된 상태

<strong>Inactive</strong>

- 앱이 전면에서 실행중이지만, 아무런 이벤트를 받지 않고 있는 상태
- 런치 스크린, 앱을 키고 가만히 두면 화면이 자동으로 꺼지는 경우

<strong>Active</strong>

- 앱이 전면에서 실행중이며, 이벤트를 받고 있는 상태

<strong>Background</strong>

- 앱이 백그라운드에 있지만 여전히 코드가 실행되고 있는 상태
- 다른 앱으로 전환되었거나 홈버튼을 눌러 밖으로 나갔을 때의 상태
- 일정 시간이 지나면 앱은 Suspended 상태로 바뀜

<strong>Suspended</strong>

- 앱이 메모리에 유지되지만 실행되는 코드가 없는 상태
- 메모리가 부족한 경우 자동으로 제거됨

## AppDelegate의 메서드 호출

앱의 생명주기 상태에 따라서 AppDelegate 객체에서 정의된 특정 메서드를 호출합니다\. 

### Unattached\(Not\-Running\)

```swift
@main
class AppDelegate: UIResponder, UIApplicationDelegate {

    func application(_ application: UIApplication, willFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey : Any]? = nil) -> Bool {
        print("-----------application(_:willFinishLaunchingWithOptions_:)------------")
        print("앱이 실행되어 초기 실행과정이 완료되기 직전에 호출되는 메소드로, 최초로 실행할 코드를 작성하면 좋습니다.")
        print("필요한 주요 객체들을 생성하고 앱 실행 준비가 끝나기 직전에 호출")
        
        return true
    }
    
    func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
        print("-----------application(_:didFinishLaunchingWithOptions_:)------------")
        print("앱 실행을 위한 모든 준비가 끝난 후, 앱이 사용자에게 화면으로 표시되기 직전에 호출")
        print("초기화 코드를 이곳에 작성")
        print("Not Running -> Foreground")
        
        return true
    }
    
    func applicationWillTerminate(_ application: UIApplication) {
        print("-----------applicationWillTerminate(_:)------------")
        print("앱이 종료되기 직전에 호출되는 메소드")
        print("사용자 데이터 등을 종료전에 한번 더 저장해두는 것이 좋습니다.")
        print("suspended 상태에서는 호출x")
    }
    
}
```

## iOS13부터의 동작\(SceneDelegate의 등장\)

SceneDelegate는 iOS13부터 추가된 UI 생명주기를 관리하는 클래스 입니다\. iOS12까지는 하나의 앱이 하나의 윈도우\(Window\)만을 가지기 때문에 AppDelegate 클래스가 UI 생명주기 관리까지 했습니다\.

이 녀석이 등장한 이후에 하나의 앱에서 여러 개의 창\(Window\)를 동시에 사용할 수 있게 되었습니다\. 그렇기 때문에 UI생명주기를 전담 관리해줄 클래스가 필요해졌습니다\.

![](<../../assets/blog/appdelegate-1392f8d779b84642821967a14ef9e245/image-006.png>)

여기서부터 <strong>Window\(화면\)</strong>의 개념이 <strong>Scene</strong>으로 바뀌고 SceneDelegate는 기존의 AppDelegate에 있넌 UI LifeCycle의 기능을 받아 각 Scene을 관리합니다\. 대신 추가적으로 AppDelegate에 Scene에 대한 정보를 관리하는 Session LifeCycle이 추가되었습니다\.

이로인해 사용자나 시스템이 새로운 scene을 만들어달라고 요청했을 때 UIKit은 scene을 만들어 Unattached 상태로 만듭니다\. 사용자가 요청한 scene은 바로 Foreground 상태를 거쳐 Active상태가 되고, 시스템이 요청한 scene은 보통 Background 상태가 되어 이벤트를 처리한 뒤 Foreground로 올라옵니다\.

![](<../../assets/blog/appdelegate-1392f8d779b84642821967a14ef9e245/image-007.png>)

즉 사용자가 앱의 UI를 해제하면 UIKit은 연결된 장면을 Background 상태로, 결국 Suspended 상태로 전환합니다\. UIKit은 언제든 Background 또는 Suspended된 scene의 연결을 끊어 리소스를 회수할 수 있고, scene을 연결되지 않은 상태로 되돌릴 수 있습니다\.

## SwiftUI에서의 AppDelegate, SceneDelegate

SwiftUI에서는 AppDelegate와 SceneDelegate를 보기 힘든데 이러한 이유는 편리성 때문입니다\. SwiftUI에서는 App이라는 프로토콜을 통해서 간편하게 초기화가 가능합니다\.

```swift
import SwiftUI

@main
struct appTestApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
    }
}
```

SwiftUI로 프로젝트를 처음 생성하면 자동으로 프로젝트 이름\.swift라는 파일이 생성됩니다\. 현재 코드가 하는 일은 단순히 ContentView\(\)를 앱 실행할 때 불러와서 화면에 띄워주는 것입니다\. 이 파일에서 AppDelegate, SceneDelegate의 업무를 모두 다 할 수 있습니다\.

```swift
import SwiftUI

@main
struct appTestApp: App {

   init() {
        xxxx.configure()
        // 앱 실행시 최초 1회 보장
        // 초기화
    }
    ///AppDelegate
    
    
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
        .onChange(of: scenePhase) { (newScenePhase) in
            switch newScenePhase {
            case .active:
                // Active 상태
            case .inactive:
                // InActive 상태
            case .background:
                // background 상태
            @unknown default:
                
            }
        }
    }
    ///SceneDelegate
}
```

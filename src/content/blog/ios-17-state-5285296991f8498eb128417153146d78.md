## @Observable

- Observation을 사용하기 위해서 기존에 사용하던 ObservableObject를 Observable\(\) macro로 변환

→ Observable\(\) macro : 컴파일을 하는 시간에 observation을 지원하기 위한 코드를 생성합니다

프로퍼티의 변경사항을 추적하기 위한 Swift 기능

```swift
//Before
class CartItem : ObservableObject {}

//After
@Observable class CartItem {}
```

- Observable을 사용할 때는 Published 프로퍼티 래퍼를 제거하고 사용합니다\.

```swift
 //Before
 @Published var cartItemData: [CartItemData] = [] 
 
 //After
 var cartItemData: [CartItemData] = [] 
```

## @State

- Observation을 완전하게 채택하기 위해서는 StateObject 대신 State를 사용합니다\.
- 기존의 값타입에서 사용하던 State와 생김새는 비슷하지만 다릅니다\.
   - State \- Binding \(값타입에서 사용하는 State\)
   - State \- Bindable \(참조타입에서 사용하는 State\)

```swift
//Before
struct MainView: View {
   
    @StateObject var cartModel = CartItem()
    var body: some View {
        TabView{
            ShopView(hotItems: $hotItems,cartModel: cartModel)
    ...

//After
struct MainView: View {
   
    @State var cartModel = CartItem()
    var body: some View {
        TabView{
            ShopView(hotItems: $hotItems,cartModel: cartModel)
    ...
```

```swift
//StateObject의 
//Before
struct MainView: View {
   
    @StateObject var cartModel = CartItem()
    var body: some View {
        TabView{
            ShopView(hotItems: $hotItems).environmentObject(cartModel)
            ...
        }
    }

//After
struct MainView: View {
   
    @State var cartModel = CartItem()
    var body: some View {
        TabView{
            ShopView(hotItems: $hotItems).environment(cartModel)

```

## @Environment

- Observation을 채택하게 되면 StateObject 대신 State를, environment\(\_:\) modifer를 이용해 environment에 추가할 수 있습니다\.

```swift
//Before
struct CartView: View {
    
    @EnvironmentObject var cartModel : CartItem
		...
}

//After
struct CartView: View {
    
    @Environment(cartItem.self) private var cartModel
		...
}

```

## @ObservedObject →

- SwiftUI에서는 body가 직접적으로 접근하는 observabale을 자동으로 추적합니다\.

## @Bindable

- Observable 타입에 바인딩이 필요하다면, ObservedObject를 Bindable 프로퍼티 래퍼로 변경하세요\.

```swift

struct CartView: View {
		//Before
    @ObservedObject var cartModel : CartItem
    
    var body: some View {
	    
	    ...
	    
    }
    
 }
 
 
 struct CartView: View {
		//After
    @Bindable var cartModel : CartItem
    
    var body: some View {
	    
	    ...
	    
		 }
    
 }
```

#### 그렇다면 Bindable이 붙는 때와 안붙는 때의 차이점이 뭔가요?

@ObservedObject가 사라지고 아무것도 붙지 않는 경우에는 View에서 프로퍼티의 값이 변화되지 않고 그저 값만 사용할 때 아무것도 붙이지 않습니다\.

```swift
struct BookView: View {
    
    var book: Book
    
    @State private var isEditorPresented = false
    
    var body: some View {
        HStack {
            Text(book.title)
            Spacer()
            Button("Edit") {
                isEditorPresented = true
            }
        }
        .sheet(isPresented: $isEditorPresented) {
            BookEditView(book: book)
        }
    }
}
```

→ View안에서 직접적인 값의 변화없이, 다른 View에서 값이 변화되면 업데이트하여 View안에서 보여줍니다\.

@ObservedObject가 사라지고 @Bindable이 붙는 경우에는 View에서 프로퍼티의 값이 변화되고, 해당 변화가 다른 View에도 영향을 미치는 것을 보여줍니다\. 

```swift
struct BookEditView: View {
		
    @Bindable var book: Book
    
    @Environment(\.dismiss) private var dismiss
    
    var body: some View {
        VStack() {
            TextField("Title", text: $book.title)
                .textFieldStyle(.roundedBorder)
                .onSubmit {
                    dismiss()
                }
                
            Button("Close") {
                dismiss()
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
    }
}
```

→ TextField에서 book\.title을 바인딩으로 받아서 값이 변화되면 위의 BookView에서 수정된 book\.Title이 보일 것입니다\.

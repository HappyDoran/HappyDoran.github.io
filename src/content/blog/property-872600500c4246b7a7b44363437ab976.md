## 모두가 알고있는 프로퍼티

클래스나, 구조체에서  선언을 해주는 상수나 변수

## 프로퍼티에 대해서 알아봅시다\.

### 저장 프로퍼티

클래스나 구조체에서만 사용할 수 있고, 값을 저장하기 위해 선언되는 상수나 변수

```swift
class Doran {
	let name : String = "도란"
	var section : String = "테크"
}

struct Doran {
	let name : String = "도란"
	var section : String = "테크"
}
```

```swift
let dongwon : Doran()

dongwon.name = "동원" //에러
dongwon.section = "디자인" //에러가 안남 
```

#### 어쩔때 에러가 나고 어쩔때 에러가 안나요…?

→ 위와 같이 let으로 선언된 클래스 인스턴스의 경우라 가정해보겠습니다\. 

클래스는 참조타입이기 때문에 지역 상수 dongwon은 스택에 할당이 되고 Doran 인스턴스는 힙에 할당이 됩니다\. 때문에 dongwon안에는 힙에서 할당된 Doran 인스턴스의 주소값이 들어있는 거죠\. 

그렇기 때문에 클래스의 경우 인스턴스 생성 당시 let으로 선언하던 var로 선언을 하던 아무런 영향을 주지 않습니다\. 

저도 이해하기 어려운 얘기라 안새겨 들어도 됩니다\.

#### 그럼 어디에 영향을 줘요?

```swift
dongwon = nil //클래스 자체가 let으로 선언이 되었기 때문에 변경이 불가

let clone : Doran()
dongwon = clone //다른 인스턴스의 주소값을 가질 수 없습니다.
```

### 지연 저장 프로퍼티

프로퍼티가 호출되기 전까지는 선언만 되고 초기화가 안되고 있다가 프로퍼티가 호출되는 순간에 초기화가 되는 저장 프로퍼티

```swift
class Contacts {
   var email: String = ""
   var address: String = ""
 
    init() { print("Contacts Init") }
}
 
class Human {
   var name: String = "unknown"
   lazy var contacts: Contacts = .init()
}

let doran : Human = .init()

```

→ 이렇게 되면 doran이라는 지역상수가 선언되었지만 doran 안의 contacts는 초기화가 안됩니다\. 

```swift
doran.contacts.address = "hello"
```

이때 이제 contacts가 초기화가 됩니다\.

### 연산 프로퍼티

get, set 이런거 쓰는 프로퍼티

저장 프로퍼티와 다르게 저장 공간을 갖지 않고, 다른 저장 프로퍼티의 값을 읽거나 선언없이  연산을 실행하고 다른 프로퍼티에 저장을 합니다\. 저장 프로퍼티의 값을 읽어서 연산을 할 경우에는 저장 프로퍼티를 var로 선언 해야합니다\. 

→  그 이유가 아니라면 저장 프로퍼티 선언없이 단순 연산의 형태로도 구현이 가능하고,클래스나 구조체 내부의 프로퍼티를 변경하고 싶다면 get, set을 사용하여  저장 프로퍼티를 변경할 수 있습니다\.

변경할 저장 프로퍼티가 있건 없건 연산 프로퍼티는 항상 var로 선언이 되어야 합니다\.

#### get

말 그대로 얻는 것, 어떤 저장 프로퍼티의 값을 연산해서 return할 것인지, 그래서 항상 return 구문이 존재

#### set

말 그대로 설정하는 것, 파라미터로 받은 값을 어떤 저장 프로퍼티에 어떻게 설정할 것인지 구현

```swift
class Person {
    var name: String = "Doran"
 
    var alias: String {
        get {
            return self.name + " 18동 106호 서식중"
        }
        set(name) {
            self.name = name + "은 야도란에서 지어진 닉네임"
        }
    }
}

```

```swift
import SwiftUI

struct DummyView: View {
    @State var doran: Person = .init()
    
    var body: some View {
        Button(doran.name){
            print(doran.alias)
            doran.alias = "도란"
            print(doran.alias)
        }
    }
}
```

#### get \- only

```swift
    var alias: String {
        get {
            return self.name + " 18동 106호 서식중"
        }
    }
    
    /*이렇게도 사용이 가능해요*/
    var alias: String {
	     return self.name + " 18동 106호 서식중"
	  }
```

### 타입 프로퍼티

static이라는 키워드를 붙이면 됩니다\.

타입 프로퍼티가 저장 프로퍼티일 경우에는 항상 초기값을 가져야 합니다\.

```swift
class Human {
	static let name : String = "도란" //초기값을 가진 저장 타입 프로퍼티
	static var section : String {
			return name + "은 테크"
	}
}
```

```swift
Doran.name
Doran.section
```

#### 연산 타입 프로퍼티의 오버라이딩

오버라이딩의 가능여부는 부모 클래스/구조체의 프로퍼티 앞에 static, class를 붙이냐에 따라 오버라이딩이 가능하냐 불가능하냐로 나뉩니다\.

```swift
class Human {
    class var alias: String { //클래스가 붙은 경우 상속이 가능합니다.
        return "Human Type Property"
    }
}
 
class Doran: Human {
    override class var alias: String {
        return "Sodeul Type Property"
    }
}

Human.alias
Doran.alias
```

```swift
class Human {
    static var alias: String {
        return "Human Type Property"
    }
}
 
class Sodeul: Human {
    override static var alias: String {     // error! Cannot override static property
        return "Sodeul Type Property"
    }
}
```

타입 프로퍼티는 모든 타입이 공통적인 값을 정의하는데 유용하게 쓰입니다\.

→ 타입 프로퍼티는 전역변수 같은 느낌으로 작동합니다\.

### 프로퍼티 옵저버

프로퍼티 값의 변화를 관찰하는 것으로, “저장 프로퍼티”에 추가할 수 있습니다\.

**이 프로퍼티가 값이 변경될 예정이야\! 그러니까 값이 변경되기 전에 값을 줄게\!\(willSet\)** 

**이 프로퍼티가 값이 방금 막 변경이 됐어\! 그러니까 값이 변경된 후에 값을 줄게\!\(didSet\)**

를 알려줍니다\.

#### willSet

```swift
var name: String = "Unknown" {
    willSet(newName) { //파라미터를 지우면 newValue로 접근이 가능
        print("현재 이름 = \(name), 바뀔 이름 = \(newName)")
    }
}

//현재 이름 = Unknown, 바뀔 이름 = Doran 출력
name = "Doran" 
```

#### didSet

```swift
var name: String = "Unknown" {
   didSet {
        print("현재 이름 = \(name), 바뀌기 전 이름 = \(oldValue)")
    }
}
 
name = "Doran"
//현재 이름 = Doran, 바뀌기 전 이름 = Unknown 출력
```

#### 정리

name이라는 값이 변경된다고 하면

1. willSet이 먼저 실행되고
1. 저장 프로퍼티 name의 값이 변경되고
1. disSet이 실행됩니다\.

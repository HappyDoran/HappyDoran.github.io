### @State

- 같은 View 안에서 현재의 상태를 나타내는 속성
- 같은 뷰가 핵심

→ 같은 View 내에서 값의 변화가 일어나게 될 때 사용합니다\.

```swift
//MainView
@State private var hotItems : [HotItem] = hotItemData
...
 var body: some View {
        TabView{
            ShopView(hotItems: $hotItems,cartModel: cartModel)
```

### @Binding

- State와 짝짜꿍하는 친구
- 하나의 프로퍼티, 값을 다른 뷰에서 사용하고 싶을 때 다른 뷰에서 선언하는 친구
- State에서 Binding으로 넘겨줄 때는 $사용 필수

→ 하위뷰의 하위뷰에서 사용하기 위해서는 계속해서 Binding을 사용해줍니다\.

```swift
//ShopView
@Binding var hotItems : [HotItem]
```

### @StateObject

- State와 거의 비슷한 역할을 합니다\.
- 사용하고자 하는 View중 최상위 View에 선언을 해놓은 후에 이후에 ObservedObject로 넘겨받습니다\.
- 다른 하위뷰들에게 값이 변경되었다고 알려주기 위해 class 내의 프로퍼티에 @published를 붙입니다\.
- \!주의 Struct는 값타입이라 사용이 불가능 합니다\.

```swift
//MainView
@StateObject var cartModel = CartItem()
  ...
   var body: some View {
        TabView{
            ShopView(hotItems: $hotItems,cartModel: cartModel)
```

### @ObservedObject

- Binding과 비슷한 역할을 합니다\.
- published된 프로퍼티를 사용하기 위해 다른 뷰에서 선언해주는 친구
- 이친구는 $안붙여도 됩니다\.

```swift
 //ShopView
 @ObservedObject var cartModel : CartItem
```

### @EnvironmentObject

- 앱의 전체 구조에서 ObservedObject를 쓰기 번거로울 때, 구조체 인자로 받아올 필요 없이 사용하기 위함

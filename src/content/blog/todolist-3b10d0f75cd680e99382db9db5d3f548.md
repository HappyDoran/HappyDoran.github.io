### 결정 필요

- Endpoint와 version
- Authentication scheme
- Maximum image size와 accepted MIME
- Signed URL expiration
- Checksum header requirement
- Measurement field semantics와 range
- Landmark versioning과 order
- Adjusted coordinate history 보존 여부
- Async status transport
- Result schema
- Retry/idempotency rule
- Retention/deletion policy

### 완료 기준

Mock adapter를 HTTP adapter로 교체한 뒤 동일 state orchestration에서 capture → upload\-session → Native binary PUT → analysis submit → status/result flow가 동작해야 한다\. Contract failure, timeout, retry와 local file release까지 automated 또는 repeatable integration verification으로 확인한다\.

- Swift에서 ` @objc ` 프로퍼티는 Objective\-C와의 상호 운용성을 위해 사용됨
- ` @objc ` 속성은 레거시 코드와의 통합이나 기존 Objective\-C 기반 프레임워크와의 상호작용을 위해 필수적
- Swift는 기본적으로 Objective\-C와 다른 런타임을 사용하지만, ` @objc ` 속성을 통해 Swift 코드가 Objective\-C 런타임에서 동작할 수 있도록 지원

### ` @objc `의 역할

- <strong>Objective\-C 노출</strong>: ` @objc ` 속성은 Swift의 메서드, 프로퍼티, 변수 등을 Objective\-C 코드에서 사용할 수 있도록 노출함
- <strong>동적 디스패치</strong>: ` @objc ` 속성은 Objective\-C의 런타임에서 동적 디스패치를 지원하기 위해 필요한 메타데이터를 생성함
- <strong>호환성</strong>: Swift 클래스가 Objective\-C 클래스의 서브클래스일 경우, ` @objc ` 속성을 사용하면 Objective\-C의 규칙을 따르는 &quot;set&quot; 메서드가 생성됨

### ` @objc ` 사용 시기

- <strong>Objective\-C와의 상호 운용</strong>: Swift 코드가 Objective\-C 코드와 함께 작동해야 할 때 사용됨
   - Objective\-C 기반의 레거시 코드와 통합하거나, Objective\-C로 작성된 라이브러리를 사용하는 경우
- <strong>UI 요소와의 상호작용</strong>: Objective\-C로 작성된 UIKit과 같은 프레임워크와 상호작용할 때 유용함
   - ` @IBAction `이나 ` @IBOutlet `과 같은 인터페이스 빌더 속성은 ` @objc `를 필요로함
- <strong>동적 기능 활용</strong>: 셀렉터, KVO와 같은 Objective\-C의 동적 기능을 활용하려는 경우 ` @objc `를 사용하여 해당 기능을 지원할 수 있음

### ` @objc `의 제한

- <strong>Swift 전용 기능 제한</strong>: ` @objc `는 제네릭, 네임스페이스와 같은 Swift의 특정 기능을 지원하지 않음
- <strong>메모리 관리</strong>: Objective\-C와의 상호 운용 시 메모리 관리가 복잡해질 수 있으며, ARC와의 호환성을 고려해야함

### Swift에서 ` @objc ` 프로퍼티를 사용할 때 추천하는 코드 구조

- <strong>클래스 전체에 </strong>` @objcMembers `<strong> 사용</strong>
   - 클래스 내부의 모든 멤버를 Objective\-C에 노출해야 하는 경우, 클래스 선언 앞에 ` @objcMembers `를 사용하면 개별적으로 ` @objc `를 지정할 필요가 없음
- <strong>개별 멤버에 </strong>` @objc `<strong> 사용</strong>
   - 클래스의 일부 멤버만 Objective\-C에 노출해야 하는 경우, 해당 멤버에만 ` @objc `를 사용함
- <strong>익스텐션을 활용한 구조화</strong>
   - Swift 클래스에 Objective\-C 기능을 추가해야 할 때, 익스텐션을 사용하여 해당 기능을 구현하고 익스텐션에 ` @objc `를 적용할 수 있음
- <strong>접근 제어자 사용</strong>
   - Objective\-C에 노출할 멤버는 ` public ` 또는 ` open `으로 선언해야함
   - ` private ` 멤버는 ` @objc `를 사용하더라도 Objective\-C에서 접근할 수 없음
- <strong>NSObject 상속</strong>
   - Swift 클래스가 Objective\-C에서 사용될 예정이라면, 해당 클래스는 ` NSObject `를 상속받아야함

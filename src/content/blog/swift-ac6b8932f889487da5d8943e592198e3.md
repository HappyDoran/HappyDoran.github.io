## 상속

기본 클래스를 기반으로 새로운 클래스를 만드는 작업입니다\. 

오직 클래스만 상속이 가능하며, 상속은 단일 상속만 가능합니다\.\(A→ A를 상속한 B → B를 상속한 C\)

```swift
class Human {
	var name: String?
	var age: Int?
}
```

```swift
class Student: Human {
	var grade: Int?
}
```

이로써 Student 클래스는 Human 클래스의 프로퍼티를 모두 가지면서 grade 프로퍼티를 추가하여 새로운 클래스로 탄생합니다\. 

```swift
import SwiftUI

class Human {
    var name: String?
    var age: Int?
}

class Student: Human{
    var grade: String?
}


let samplePerson: Student = Student()

samplePerson.grade
samplePerson.age
samplePerson.name
```

### 상속에서의 메소드

당연히 상속 가능합니다\.

```swift
class Human {
    var name: String?
    var age: Int?
    
    func getName(name:String) {
        print("제 이름은 \(name) 입니다.")
    }
}

class Student: Human{
    var grade: String?
}


let samplePerson: Student = Student()

samplePerson.name = "민수"

if let name = samplePerson.name {
    samplePerson.getName(name: name)
}
```

### 더이상 상속할 필요가 없다면?

```swift
final class Human {
	var name: String?
	var age: Int?
}
```

더이상 상속받을 필유가 없다면 final을 사용하여 상속을 제한함으로서 빌드 속도를 향상시킵니다\. 

### 오버라이딩

재정의 \- 상속을 받은 프로퍼티나 메소드를 다른 기능을 하게 하고싶을 때 서브 클래스에서 다시 정의하는 것

```swift
class Human {
    var name: String?
    var age: Int?
    
    func getName(name:String) {
        print("제 이름은 \(name) 입니다.")
    }
}

class Student: Human{
    var grade: Int?
    
    override func getName(name: String) {
        print("제 이름은 \(name)이고 점수는 \(self.grade ?? 0)점 입니다")
    }
}


let samplePerson: Student = Student()

samplePerson.name = "민수"
samplePerson.grade = 100

if let name = samplePerson.name {
    samplePerson.getName(name: name)
}

```

#### 슈퍼 클래스의 메소드도 쓰고싶다면?

```swift
class Student: Human{
    var grade: Int?
    
    override func getName(name: String) {
        super.getName("")
        print("제 이름은 \(name)이고 점수는 \(self.grade ?? 0)점 입니다")
    }
}


```

### 상속받은 프로퍼티 오버라이딩

서브 클래스에서는 상속된 프로퍼티의 특성이 저장 프로퍼티인지, 연산 프로퍼티인지 알 수 없으며, 상속받은 프로퍼티의 이름과 타입 정도만 알고 있다\.

때문에 프로퍼티를 오버라이딩 할 거면 “프로퍼티의 이름”과 “타입”을 반드시 명시해라\.

#### 저장프로퍼티의 상속

```swift
class Human {
    var name = "SamplePerson"
}
 
class Student: Human {
    override var name: String = "SamplePerson2"       // Cannot override with a stored property 'name'
}

```

```swift
class Student: Human {
    var alias = "SamplePersonSamplePerson"
 
    override var name: String {     //Cannot override mutable property with read-only property 'name'
        return self.alias
    }
}
```

#### 결론

수퍼클래스에서 상속하고자 하는 프로퍼티가 저장 프로퍼티일 경우, 저장프로퍼티는 읽기&amp;쓰기가 모두 가능한 프로퍼티이기 때문에 서브 클래스에서 getter와 setter를 모두 선언해줘야 상속이 가능하다\. 

#### 이상적인 저장프로퍼티의 상속

```swift
class Teacher: Human {
    var alias = "SamplePersonSamplePerson"
 
    override var name: String {   
        get {
            return self.alias
        }
        set {
            self.alias = newValue
        }
    }
}
```

#### 연산 프로퍼티의 상속

연산프로퍼티도 마찬가지로 수퍼클래스에서의 프로퍼티가 읽기전용 연산 프로퍼티일 경우 서브 클래스에서는 getter로만 구현하거나, setter를 추가로 구현하는 오버라이딩이 가능하다\.

하지만 읽기, 쓰기 연산 프로퍼티일 경우 무조건, getter와 setter를 포함하여 오버라이딩을 해야 한다\.

```swift
import SwiftUI

class Human {
    var name = "Alex"
 
    var alias: String {
        return self.name + " 바보"
    }
}

class Student: Human {
    override var alias: String {
        return self.name + " 멍청이"
    }
}

var samplePerson = Teacher()

print(samplePerson.alias)
print(samplePerson.name)

```

```swift
import SwiftUI

class Human {
    var name = "Alex"
 
    var alias: String {
        get{
            return self.name + " 바보"
        }
        set{
            self.name = newValue
        }
    }
}

class Student: Human {
    override var alias: String {
        get{
            return self.name + " 멍청이"
        }
        set{
            self.name = newValue
        }
    }
}

var samplePerson = Student()

print(samplePerson.alias)
print(samplePerson.name)
```

## 타입 캐스팅

인스턴스의 타입을 확인하거나, 해당 인스턴스를 슈퍼 클래스나 하위 클래스로 취급하는 방법이다\.

is나 as를 사용하여 구현하며, 타입 캐스팅을 사용하여 타입이 프로토콜에 적합한지 여부도확인할 수 있다\.

### is : 타입 체크

타입을 체크하는 연산자

type이 일치하거나, type이 서브 클래스인 경우에 true를 반환한다\.

```swift
class Human {...}
class Student: Human {...}
 
let student: Student = .init()
student is Student      // true
student is Human        // true
```

### as: 타입 캐스팅

표현식 as  \(변환 할\)Type

표현식 as? \(변환 할\)Type

표현식 as\! \(변환 할\)Type

표현식의 타입이 변환할 타입과 호환된다면, 변환할 타입으로 캐스팅된 인스턴스를 리턴한다\.

상속 관계인 업캐스팅과 다운캐스팅에서 사용한다\.

#### 업 캐스팅

서브 클래스의 인스턴스를 “슈퍼 클래스의 타입”으로 참조한다\.

→ 레벨업 같은 느낌인 것 같습니다\.

```swift
class Human {...}
class Student: Human {...}

let human = Student.init() as Human
// Student 타입의 인스턴스를 생성하지만,
// 이를 Human 타입으로 업캐스팅해서 human에 저장하겠다. 

let people: [Human] = [
    Teacher.init(name: "김선생") as Human, //이렇게 써도 되고,
    Student.init(name: "박제자"), // 앞에 타입을 명시해서 생략해도 됨
    Student.init(name: "유제자")
]
```

둘의 슈퍼 클래스가 Human으로 동일하기 때문에, 이 둘을 Human이란 클래스로 업캐스팅 해서 묶어버린 것입니다\.

as: “컴파일 시점”에 타입 캐스팅\(업캐스팅\)을 하며, 실패할 경우 에러가 발생한다\.

![](<../../assets/blog/swift-ac6b8932f889487da5d8943e592198e3/image-001.png>)

위의 예시에서 human의 타입은 업캐스팅 된 Human의 타입입니다\.

하지만 Human의 인스턴스만 메모리에 올라가는 것이 아닌 처음에 Teacher 타입의 인스턴스를 만들었기 때문에, Teacher 인스턴스가 메모리에 올라갑니다\.

하지만 업캐스팅을 함으로서, human의 접근범위가 Human 멤버로 한정이 되는 것이지요\. 그렇기 때문에

```swift
human.name             // SamplePerson
human.subject          // Value of type 'Human' has no member 'subject'
```

Teacher 타입의 멤버인 subject에는 접근할 수 없는 모습을 보입니다\.

#### 다운 캐스팅

슈퍼 클래스 인스턴스를 “서브 클래스 타입”으로 참조한다\.

→ 레벨다운 같은 느낌

업캐스팅된 인스턴스를 다시 원래 서브 클래스 타입으로 참조할 때도 사용한다\.

다운 캐스팅은 실패할 수 있기 떄문에 as?, as\!의 연산자를 사용한다\.

업 캐스팅을 할 경우, 슈퍼 클래스\(Human\)의 멤버만 접근이 가능했었다\. 

이걸 이제 Teacher 멤버에 접근 가능하게 하고 싶으면? 다운 캐스팅을 사용해라\.

```swift
var teacher: Teacher = human as! Teacher
```

→ Human 타입으로 업캐스팅된 human 변수를 다시 하위 클래스인 Teacher 타입으로 변환해서 넣어주면 다운 캐스팅이 됩니다\.

![](<../../assets/blog/swift-ac6b8932f889487da5d8943e592198e3/image-002.png>)

이렇게 teacher란 변수는 Teacher 클래스로 다운 캐스팅이 됐기 때문에, Teacher 클래스의 멤버인 subject에 접근이 가능합니다\.

#### as?와 as\!의 차이점

다운캐스팅은 실패할 수 있으므로 옵셔널을 통해 이루어집니다\.

as? \- “런타임 시점”에 다운 캐스팅을 하며, 실패할 경우 nil을 리턴

as\! \- “런타임 시점”에 다운 캐스팅을 하며 , 실패할 경우 에러를 발생

→ 가능하면 as?를 사용하여 옵셔널 바인딩을 통해 안전하게 추출해냅시다\.

```swift
for human in people {
   if let teaher =  human as? Teacher {
        print("나는야 선생님 : \(teacher.name)")
    } else if let student =  human as? Student {
        print("나는야 제자  : \(student.name)")
    }
}
```

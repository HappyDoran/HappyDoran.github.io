## Generic

타입에 의존하지 않는 범용적 코드를 작성할 때 사용합니다\.

제네릭을 사용하면 중복을 피하고, 코드를 유연하게 작성할 수 있습니다\.

→ Swift의 표준 라이브러리의 대다수는 제네릭으로 선언 되어있습니다\!

### 제네릭 함수

만약 파라미터로 오는 두 Int 타입의 값을 swap하는 함수를 만들고 싶다 해봅시다\.

```swift
func swapTwoInt(_ a: inout Int, _ b: inout Int) {
    let tmpA = a
    a = b
    b = tmpA
}
```

이렇게 되면 파라미터 Int일 경우에는 문제 없이 돌아갑니다\.

하지만 파라미터가 Double, String일 경우에는 사용할 수 없죠…

> 🐣 <strong>In\-Out Parameters</strong>
> 
> Swift에서 함수의 파라미터는 상수\(Constant\)이므로 함수 내부에서 파라미터의 값을 변경할 수 없다\. 이는 우리가 파라미터를 실수로라도 변경할 수 없다는 뜻이기도 하다\. 만약 함수에서 파라미터의 값을 변경하고, 변경된 값이 함수 호출이 종료된 후에도 지속되길 원한다면 ` inout ` 파라미터를 사용하면 된다\.
> 
> <strong>Inout의 원리</strong>
> 
> inout 매개변수는 다음의 과정을 거친다\.
> 
> 1. 함수가 호출되면, 매개변수로 넘겨진 변수가 복사된다\.
> 1. 함수 몸체에서, 복사한 값을 수정한다\.
> 1. 함수가 반환될 때, 변화된 값을 원본 변수에 재할당한다\.

만약 파라미터의 타입이 Double이나, String일 경우에는 

```swift
func swapTwoDoubles(_ a: inout Double, _ b: inout Double) {
   let tempA = a
   a = b
   b = tempA
}

func swapTwoStrings(_ a: inout String, _ b: inout String) {
   let tempA = a
   a = b
   b = tempA
}
```

이런식으로  하나하나 오버로딩 해줘야하는데, 이 무슨 낭비입니까…

이럴때 사용하는게 제네릭입니다\. 타입에 제한을 두지 않는 코드를 사용하고 싶을 때 씁니다\!

```swift
func swapTwoValues<T>(_ a: inout T, _ b: inout T){
    let tmpA = a
    a = b
    b = tmpA
}
```

꺽쇠&lt;&gt;를 이용해서  안에 타입처럼 사용할 이름\(T\)를 선언해주면,  해당 이름\(T\)를 타입처럼 사용할 수 있습니다\!

여기서 이 T는 Type Parameter라고 부르는데, T라는 새로운 타입이 생성된 것이 아니라,

 실제 함수가 호출 될 때 해당 매개변수의 타입으로 대체가 되는 자리라고 보시면 될 것 같습니다\.

→ Swift에게 “여기는 타입이 아니라, 함수가 호출될 때 그 타입이 들어가기 위한 자리야” 라고 하는 것입니다\.

```swift
var someInt = 1
var anotherInt = 2

swapTwoValues(&someInt, &anotherInt) //함수가 호출되면 T는 Int타입으로 결정됩니다.
```

여기서 a, b는 모두 같은 타입 파라미터인 T로 선언이 되어 있기 때문에,

```swift
swapTwoValues(&someInt, &aotherString)
```

이건 안된다\.

#### 결론

똑같은 내용의 함수를 오버로딩 할 필요 없이 제네릭을 사용하면, 코드 중복을 피하고 유연하게 코드를 짤 수 있습니다\.

### 제네릭 타입

제네릭은 함수에만 가능한 것이 아니라, 구조체, 클래스, 열거형 타입에도 선언할 수 있는데,  이것을 제네릭 타입이라고 합니다\. 

```swift
struct Stack<T> {
    var items: [T] = []
    
    init(items: [T]) {
        self.items = items
    }   
}

var stackA: Stack<Int> = .init(items: [1,2,3])
var stackB: Stack<String> = .init(items: ["a","b","c"])
```

뭔가 어디서 많이 보던 선언 같으면 기분탓이 아닙니다\.

```swift
let array: Array<Int> = [1,2,3]
```

배열을 선언할 때와 똑같네요\.

## 타입 제약

제네릭 함수와 타입을 사용할 때 특정 클래스의 하위 클래스나, 특정 프로토콜을 준수하는 타입만 받을 수 있게 제약을 둘 수 있습니다\.

### 프로토콜 제약

만약 우리가 파라미터로 두개의 값을 받아서 두 값이 같으면 true, 다르면 false를 반환하는 함수를 제네릭으로 선언한다고 해봅시다\.

```swift
func isSameValues<T>(_ a: T, _ b: T) -> Bool {
    return a == b               // Binary operator '==' cannot be applied to two 'T' operands
}
```

== 연산자는 a와 b가 Equatable 프로토콜을 준수할 때만 사용할 수 있기 때문에 

T가 Equatable 할수도 있고 아닐수도 있는데 어째서 ==를 쓰냐 하고 에러를 뱉어버립니다\. 

→ 그래서 이때는

```swift
func isSameValues<T: Equatable>(_ a: T, _ b: T) -> Bool {
    return a == b
}
```

이렇게 T: Equatable로 타입에 제약을 줄 수 있습니다\. 

### 클래스 제약

프로토콜 제약과 동일하지만 해당 자리에 클래스가 오는 겁니다\.

```swift
class Bird { }
class Human { }
class Teacher: Human { }
 
func printName<T: Human>(_ a: T) { }
```

이렇게 작성해주면 

```swift
let bird = Bird.init()
let human = Human.init()
let teacher = Teacher.init()
 
printName(bird)                  // Global function 'printName' requires that 'Bird' inherit from 'Human'
printName(human)
printName(teacher)
```

Human 클래스 인스턴스인 human과, Human 클래스를 상속받은 teacher는 printName이란 제네릭 함수를 실행할 수 있지만, bird는 실행할 수 없습니다\.

## 제네릭 확장

만약 제네릭 타입인 Array를 확장하고 싶다면 어떻게 해야 할까요?

기존의 Array의 경우 실제 구현부에서 타입 파라미터가 Element이기 때문에 무조건 Element로 작성해야 합니다\.

```swift
extension Array {
    mutating func pop() -> Element {
        return self.removeLast()
    }
}
```

### Where

where를 통해서 확장 또는 제약을 줄 수 있는데

```swift
extension Array where Element: FixedWidthInteger {
    mutating func pop() -> Element { return self.removeLast() }
}

```

이렇게 타입 파라미터인 Element가 FixedWidthInteger 프로토콜을 준수해야한다라는 제약을 줄 수 있습니다\. 

## 제네릭 함수와 오버로딩

제네릭은 보통 타입에 관계없이 동일하게 실행되지만, 특정 타입일 경우 제네릭 말고 다른 함수로 구현하고 싶다면 제네릭을 오버로딩 하면 됩니다\.

```swift
func swapValues<T>(_ a: inout T, _ b: inout T) {
    print("generic func")
    let tempA = a
    a = b
    b = tempA
}
 
func swapValues(_ a: inout Int, _ b: inout Int) {
    print("specialized func")
    let tempA = a
    a = b
    b = tempA
}
```

이렇게 되면 타입이 Int로 지정된 함수가 제네릭 함수보다 우선순위가 더 높아서 

```swift
var a = 1
var b = 2
swapValues(&a, &b)          //"specialized func"
 
 
var c = "Hi"
var d = "Sodeul!"
swapValues(&c, &d)          //"generic func"
```

이렇게 분류가 됩니다\.

#### 이름 짓기

Lower Camel Case : 함수, 메소드, 변수, 상수 등

Upper Camel Case : 클래스, 구조체, enum, 익스텐션 

#### 콘솔로그

print : 단순 문자열만 출력

dump : 인스턴스의 자세한 요소들까지 출력해줌

#### 문자열 보간

프로그램 실행 중 문자열 내에 변수 또는 상수의 값 표현

\\\(\)

```swift
import Swift

let age : Int = 10
print("안녕하세요 ! 저는 \(age)살입니다")
//안녕하세요 저는 10살입니다
```

## 모두가 알고있는 메소드

클래스나, 구조체에서  선언을 해주는 함수\(func 맞습니다\.\)

## 메소드에 대해서 알아봅시다\.

### 인스턴스 메소드

인스턴스와 연관된 메소드

인스턴스를 생성해야지만 호출이 가능합니다\.

```swift
class Person {
		func thisIsInstanceMethod(){
				print("This is InstanceMethod")
		}
}
...
let doran : Person = Person()
doran.thisIsInstanceMethod()
```

→ 인스턴스 메소드는 “인스턴스”와 관련된 메소드이기 때문에 “인스턴스를 생성해야지만” 접근할 수 있습니다\.

### 타입 메소드

타입과 연관된 메소드

인스턴스의 생성 없이 타입의 이름만 알면 호출이 가능합니다\.

메소드 선언시에 static\(상속 불가\)나 class\(상속 가능\)가 붙으면 그 메소드는 타입 메소드입니다\.

```swift
class Person {
		static func thisIsStaticTypeMethod(){ //상속 불가
				print("This is TypeMethod")
		}
		class func thisIsClassTypeMethod(){ //상속 가능
				print("This is TypeMethod")
		}
}
...
Person.thisIsStaticTypeMethod()
Person.thisIsClassTypeMethod()
```

→ 클래스를 상속하냐, 상속하지 않냐에 따라서class, static을 골라서 쓰시면 됩니다\.

### 메소드에서의 멤버 접근 범위

말이 좀 어렵긴 한데 그냥 메소드 안에서 클래스나 구조체에서 선언한 프로퍼티를 쓸 수 있는지 아닌지에 대해서 적어본 겁니다\.

```swift
class Person {
		let name = "doran" //저장 프로퍼티
		static let alias = "yadoran" //저장 타입 프로퍼티
		
		func thisIsInstanceMethod(){ //인스턴스 메소드
				print(name)            
        print(Person.alias)
		}
		
		static func thisIsStaticTypeMethod(){ //상속 불가능한 타입 메소드
				print(name)              // error! Instance member 'name' cannot be used on type 'doran
        print(alias)
		}
		class func thisIsClassTypeMethod(){ //상속 가능한 타입 메소드
				print(name)              // error! Instance member 'name' cannot be used on type 'doran
        print(alias)
		}
}
```

타입 메소드 안에서는 타입 프로퍼티만 사용이 가능합니다\.

인스턴스 메소드 안에서는 타입 프로퍼티의 타입\(Person\)만 알고 있으면 타입 프로퍼티 사용이 가능합니다\.
